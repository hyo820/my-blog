# 안녕하세요

이 블로그는 마크다운 파일을 읽어 **정적 HTML**로 변환하는 빌드 스크립트로 만들어졌습니다. 프레임워크나 번들러 없이 순수 HTML, CSS, JavaScript만 사용합니다.

## 지원하는 문법

- 제목, 문단, 목록
- *기울임*과 **굵게**
- [링크](https://example.com)
- 인라인 코드 `const x = 1`
- 코드 블록과 문법 강조

간단한 자바스크립트 예제입니다.

```javascript
// 두 수를 더하는 함수
function add(a, b) {
  return a + b;
}

const result = add(2, 3);
console.log("결과:", result);
```

> 이 사이트는 빌드 타임에 `node build.js`로 생성됩니다.

읽어주셔서 감사합니다.
