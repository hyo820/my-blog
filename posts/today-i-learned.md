# 오늘 배운 것

클로드 코드와 함께 프레임워크 없이 블로그를 직접 만들어보면서, HTML·CSS·JavaScript 각각이 실제로 어떤 역할을 맡는지 다시 정리해볼 수 있었습니다.

## HTML: 콘텐츠의 구조

HTML은 글의 뼈대를 담당합니다. 이 블로그에서는 마크다운을 파싱해서 제목(`h1`~`h6`), 문단(`p`), 목록(`ul`/`ol`), 인용구(`blockquote`), 코드 블록(`pre`/`code`) 같은 태그로 변환합니다. 프레임워크 없이도 의미에 맞는 태그를 고르는 것만으로 구조가 명확해진다는 걸 느꼈습니다.

## CSS: 보기 좋게 만드는 규칙

CSS는 같은 HTML을 라이트/다크 두 가지 모습으로 보여주는 역할을 합니다.

- CSS 커스텀 프로퍼티(변수)로 색상 팔레트를 한 곳에 모아두면 다크모드 전환이 훨씬 쉬워집니다.
- `prefers-color-scheme` 미디어 쿼리로 시스템 설정을 감지하고, `data-theme` 속성으로 사용자가 직접 고른 테마를 덮어씁니다.
- 미디어 쿼리 하나만 잘 잡아도 모바일에서 레이아웃이 깨지지 않게 만들 수 있습니다.

## JavaScript: 상호작용 처리

JavaScript는 이 블로그에서 아주 적은 역할만 맡습니다.

1. 페이지 로드 시 `localStorage`와 시스템 설정을 확인해 초기 테마를 결정
2. 토글 버튼 클릭을 감지해서 테마를 전환하고 `localStorage`에 저장

콘텐츠 자체는 빌드 타임에 이미 HTML로 만들어지기 때문에, 브라우저에서는 딱 필요한 상호작용만 JavaScript가 처리하면 됩니다.

## 정리

세 가지 언어가 각자의 역할에 집중하도록 나누니 코드가 훨씬 단순해졌습니다. 프레임워크 없이도 충분히 깔끔한 블로그를 만들 수 있다는 걸 직접 확인한 하루였습니다.
